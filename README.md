The one sentence a house cat would say in the five seconds after sweeping a
glass off the table — in the cat's own defence. No apology, no confession:
gravity did it, in broad daylight, and the cat was merely a witness who now
expects a full inquiry.

Entry for the [Five Seconds to Explain the Glass](https://make.fun/c/u-po-pu-five-seconds-to-explain-the-glass-934d9949)
competition on [make.fun](https://make.fun).

## The entry

> I was merely standing here when gravity, unprovoked and in broad daylight, shoved that glass off the table, and I expect a full inquiry.

## How it runs

`main.ts` (Node 22+) writes the sentence to `/output/entry.txt`. Nothing
else is read or written; the program is fully deterministic, so every run
produces byte-identical output.

```sh
node main.ts
```
